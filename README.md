# Geisha Fan Dance Animation 🏯

![Project Preview](Screenshot_Gaisha.png)

A stylized, generative animation of a Geisha figure performing a simple fan movement, built entirely with standard Python libraries.

## 📝 Description
This project focuses on using basic geometric shapes to procedurally draw a stylized Geisha figure and animate a folding fan. It demonstrates the capability of Python's built-in Tkinter library for creative, non-game related graphical simulations.

## ✨ Key Features
* **Procedural Drawing:** The Geisha figure is constructed purely from polygons and circles—no external image files are used.
* **Sine-Wave Animation:** The fan's gentle swaying motion is controlled by the `math.sin()` function, creating smooth, realistic movement.
* **Lightweight:** The script runs with zero external dependencies, making it easily shareable.
* **Atmosphere:** Includes a subtle particle effect (falling petals) to tie the project back to a Japanese aesthetic.

## 🛠️ Built With
* **Python 3.x**
* **Tkinter** (Standard GUI library for Python)

## 🚀 How to Run
1.  Ensure you have Python installed.
2.  Download the file `Geisha.py`.
3.  Run the script via terminal:
    ```bash
    python Geisha.py
    ```
